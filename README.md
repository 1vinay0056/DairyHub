# 📌 Project Overview

**DairyHub** is a modern Full Stack Dairy E-Commerce platform that enables customers to purchase fresh dairy products online while providing administrators with a complete dashboard to manage products, users, orders, and customer interactions.

The project is built using **React + TypeScript + Tailwind CSS** for the frontend and **FastAPI + MongoDB** for the backend with JWT Authentication.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/1vinay0056/DairyHub.git
```

---

## Frontend

```bash
cd dairyhub-frontend

npm install

npm run dev
```

---

## Backend

```bash
cd dairyhub-backend

pip install -r requirements.txt

uvicorn main:app --reload
```

---

# ⚙ Backend Environment Variables

Create `.env`

```env
MONGO_URI=YOUR_MONGODB_URI

SECRET_KEY=YOUR_SECRET_KEY

ALGORITHM=HS256

ACCESS_TOKEN_EXPIRE_MINUTES=1440
```

---

# ⚙ Frontend Environment Variables

Create `.env`

VITE_API_URL=https://dairyhub-rdgj.onrender.com
